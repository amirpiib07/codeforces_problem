Formally, the score of $$$b$$$ is equal to the maximum integer $$$k$$$ for which there exists an index $$$i$$$ such that: </p><ul> <li> $$$1 \leq i \leq m - k + 1$$$ </li><li> $$$b_i = b_{i+k-1} = 1$$$ </li><li> $$$b_{i+1} = b_{i+2} = \ldots = b_{i+k-2} = 0$$$ </li></ul><p>If there is no subarray meeting the requirements, the score of $$$b$$$ is $$$0$$$.</p><p>You are given an array $$$a_1, a_2, \ldots, a_n$$$, such that each element is equal to one of $$$-1$$$, $$$0$$$, or $$$1$$$.
